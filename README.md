    #Автоматизація тестування сайту Rozetka (C# + Selenium)

Мій перший практичний проєкт з автоматизації UI-тестів для вебсайту "Rozetka" за допомогою мови програмування "C#" та фреймворку "NUnit".

   🚀 Використаний технологічний стек
* Мова програмування: C# (.NET 10.0)
* Тестовий фреймворк: NUnit 4
* Інструмент автоматизації: Selenium WebDriver
* Браузер: Mozilla Firefox (GeckoDriver)
* Середовище розробки: Visual Studio 2026

   📋 Сценарій тесту (`OpenBrowser_ShouldStartFirefox`)
У проєкті реалізовано **негативний тест-сценарій** за структурою "AAA (Arrange, Act, Assert)":
1. *Arrange*: Підготовка базового URL сайту та ініціалізація розумного очікування `WebDriverWait`.
2. *Act*: 
   * Перехід на головну сторінку сайту.
   * Клік по кнопці профілю користувача за допомогою надійного кліку через JavaScript `IJavaScriptExecutor` (для обходу блокуючих банерів).
   * Введення невалідного номера телефону (`123456789`) у поле вводу.
   * Натискання зеленої кнопки "Продовжити".
3. *Assert*: Перевірка реакції системи (сайт успішно підсвічує поле червоним та виводить попередження про необхідність введення коректного номера).

   🛠️ Як запустити тести локально
1. Склонуйте цей репозиторій до себе на комп'ютер.
2. Відкрийте проєкт у "Visual Studio".
3. Переконайтеся, що всі пакети NuGet успішно відновлені.
4. Відкрийте "Test Explorer" (Оглядач тестів).
5. Натисніть кнопку "Run All" (Запустити всі тести).
